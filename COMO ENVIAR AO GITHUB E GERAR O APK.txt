SMART NOTES 1.4.1 - GITHUB E APK
================================

PASTA QUE DEVE SER ENVIADA
--------------------------
Use somente a pasta:

02 - GitHub - Repositorio Completo

Ela nao possui banco pessoal, backups, node_modules ou chaves privadas.

PRIMEIRO ENVIO
--------------
1. O repositorio existente pode ser usado:
   https://github.com/LuanClaiver/Smart-Notes

2. Dentro da pasta 02, execute:
   ENVIAR REPOSITORIO COMPLETO.bat

3. Quando a URL for solicitada, pressione Enter para usar:
   https://github.com/LuanClaiver/Smart-Notes.git

4. Autorize o Git Credential Manager caso o navegador seja aberto.

5. Aguarde a mensagem de envio concluido.

GERAR APK IMEDIATAMENTE PARA TESTE
----------------------------------
1. Abra o repositorio no GitHub.
2. Entre em Actions.
3. Abra 02 - Gerar APK Android.
4. Clique em Run workflow e confirme.
5. Aguarde a execucao ficar verde.
6. Abra a execucao e baixe o artefato Smart-Notes-APK.
7. Extraia e instale Smart-Notes.apk no celular.

Sem segredos de assinatura, o fluxo gera um APK de teste. Para instalar outra compilacao de teste feita em uma nova execucao, talvez seja necessario desinstalar a anterior primeiro.

GERAR APK ASSINADO PARA RECEBER ATUALIZACOES
---------------------------------------------
No repositorio, abra:
Settings > Secrets and variables > Actions

Crie estes segredos:

ANDROID_KEYSTORE_PASSWORD
ANDROID_KEY_ALIAS
ANDROID_KEY_PASSWORD

Valor sugerido para o alias:
smart-notes

Depois:
1. Abra Actions.
2. Execute 01 - Gerar chave Android.
3. Baixe o artefato chave-smart-notes.
4. Guarde permanentemente smart-notes-release.jks.
5. Abra keystore-base64.txt e copie todo o conteudo.
6. Crie o quarto segredo:
   ANDROID_KEYSTORE_BASE64
7. Cole nele todo o conteudo do arquivo.
8. Execute novamente 02 - Gerar APK Android.

Com os quatro segredos configurados, o fluxo gera o APK de lancamento assinado. Use sempre a mesma chave e as mesmas senhas para as atualizacoes futuras.

ATUALIZACOES FUTURAS
--------------------
Dentro da pasta do repositorio conectado, execute:

ATUALIZAR GITHUB.bat

Quando a pasta mobile-app for modificada, o GitHub inicia novamente a geracao do APK.

IMPORTANTE SOBRE DADOS PUBLICOS
-------------------------------
O aplicativo Android desta versao funciona offline. Uma nota publica aparece para outros usuarios cadastrados no mesmo banco local do aparelho.

Para usuarios em celulares diferentes enxergarem as notas publicas em tempo real, sera necessario criar uma futura versao com servidor hospedado ou sincronizacao em nuvem.
